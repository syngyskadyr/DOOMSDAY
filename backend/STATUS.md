## Работает

- Все операции HTTP API v1: импорт, список/карточка, фильтры, версии чек-листов,
  фоновые оценки, апелляции и атомарный пересчёт.
- SQLite сохраняет диалоги, задачи, оригинал/финал, версии и журнал решений.
  Зависшие задания после перезапуска становятся failed без повтора модели.
- Адаптер вызывает `validate_response`, затем общий `calculate_score`.
  Исторические результаты используют свой `checklist_snapshot`; Decimal
  преобразуется в JSON number, неизвестные значения остаются null.
- Backend читает корневой `.env` или `--env-file`, с приоритетом окружения
  процесса. `--no-env-file` отключает чтение; значения не интерполируются.
- Публичная сборка подключается `--frontend <каталог>` и раздаётся с API на
  одном origin. Явно несуществующий каталог даёт понятную ошибку запуска.
- `/docs` содержит JSON-редакторы POST-запросов и синтетический пример импорта.

## Интеграция и общий комплект

В текущей `main` (`3a22336`) есть `frontend/public/index.html` и ассеты:
отдельная сборка не требуется. В рабочей ветке `feat/backend` frontend нет;
это различие веток, а не отсутствие реализации на GitHub.

Этот коммит публикует пять отсутствовавших общих файлов:
`HTTP_API_CONTRACT.md`, `fixtures/http_examples.json`, `BACKEND_PROMPT.md`,
`FRONTEND_PROMPT.md` и `TEAM_START.md` в `codex_context/team/`.
Контракт сверен с backend, задания отмечены как исходные, инструкция описывает
существующий frontend. Синтетические original/final точно совпали с результатом
общего валидатора/scorer через `MLAdapter.result_state`; лишние секции без
весовых критериев удалены из примеров. Реальных DEV ID, реплик, audio_url,
секретов и личных данных в публикуемых материалах не обнаружено.

`TEAM_PACK_CHECK.json` оставлен локально без изменений: это одноразовый отчёт
о комплекте от 7 ноября без воспроизводимой проверки текущего приложения.
Полных дубликатов среди пяти добавляемых файлов и отслеживаемых файлов нет.
Повторение чек-листа и синтетического assessment внутри HTTP-примеров нужно
для полных примеров HTTP-обёртки и не заменяет канонические ML-материалы.
