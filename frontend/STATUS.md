# Статус frontend DOOMSDAY

## Этап 1. Диалоги и оценивание

- [x] Рабочая область FastAPI с импортом JSON, поиском по ID, фильтрами и пагинацией.
- [x] Карточка диалога с исходными репликами, аудиоплеером, версией чек-листа и историей запусков.
- [x] Отображение задания и результата, переход к доказательствам, N/A, проверенные участки и грубые ошибки.
- [x] Аналитика последних оценок: статусы, распределение баллов, выборка грубых ошибок.

Проверены 5 frontend-тестов, 37 тестов FastAPI и браузерный сценарий импорта, поиска, фильтров, пагинации, карточки и аналитики на тестовых записях. Проверен мобильный реестр. Без настройки LLM приложение показывает сообщение от API и не создаёт оценку.

## Этап 2. Чек-листы и апелляции

- [x] Настройка формулировок, весов, типов ответов, шкал, N/A и флагов. Добавление критериев и сохранение новой версии в FastAPI.
- [x] Просмотр предыдущих версий и повторный запуск оценки по обновлённым правилам.
- [x] Апелляция по критерию, подтверждение или изменение ответа, доказательства, история, исходная и итоговая оценки.
- [x] Полный сценарий в Chrome через FastAPI и SQLite с явно подключённым тестовым адаптером команды.

## Итог проверки

- 12 frontend-тестов и 37 backend-тестов прошли. JavaScript проверен через `node --check`, установка зависимостей через `pip check`.
- Браузерный прогон охватил импорт, поиск, фильтры, пагинацию, очередь, 8 исходных и 9 критериев после изменения, N/A, выделение реплик, воспроизведение и перемотку тестового аудио. Проверены обе ветки апелляции, сохранение исходной оценки, фильтр грубых ошибок, ошибка оценщика и мобильная компоновка.
- В ML-наборе прошёл 31 из 34 тестов. Для оставшихся трёх нужен локальный `codex_context/data/dev.json`. Реальный вызов модели не выполнялся, параметры LLM в окружении проверки отсутствовали.
- В репозитории команды на момент интеграции не было `FRONTEND_PROMPT.md` и `HTTP_API_CONTRACT.md`. Использованы действующие маршруты и тесты FastAPI, командный handoff и контракт ML.
