# DOOMSDAY — старт ML-части через Codex

Этот комплект — задание и материалы для Codex. Он ещё не является работающим оценщиком и не содержит измеренной точности модели.

## Запуск

1. Распакуй архив в корень своего репозитория DOOMSDAY. Должна появиться папка codex_context рядом с README проекта.
2. Открой весь проект DOOMSDAY в VS Code и открой Codex.
3. Отправь: «Прочитай codex_context/CODEX_PROMPT.md и выполни задание. Сначала кратко обозначь план, затем реализуй и проверь ML-оценщик. Соблюдай существующие инструкции репозитория. Если доступ к API не настроен, закончи всю доступную оффлайн-часть и укажи, какие настройки нужны для одного реального запуска».
4. Пока Codex работает, участники frontend и backend могут прочитать team/HANDOFF.md и согласовать формат обмена.
5. Прочитай итог Codex: что действительно запущено, какие тесты прошли, был ли реальный вызов модели и что осталось подключить.

Выбранная сильная модель Codex пишет код. Для работы создаваемого приложения нужен настроенный доступ к модели через API. Секретный ключ вводится локально в .env; его нет в архиве.

## Какой результат должен дать первый запуск Codex

Работающий Python-модуль: загрузить один разговор, собрать запрос из текущего чек-листа, получить ответ модели при настроенном API, проверить его и рассчитать результат. CLI должен уметь работать с файлами и показать реальное состояние, включая отсутствие API-доступа.

Критерии оценивает LLM; веса, N/A и округление считает обычный код. Frontend, база данных и обработка апелляций подключаются участниками команды к этому модулю.

## Работа с данными и Git

Вложенный .gitignore исключает data/ и будущие результаты из этого каталога. Codex должен дополнить корневой .gitignore для .env, данных, результатов, аудио и виртуального окружения, сохраняя существующие правила.
Перед публичной сдачей проверь git status: DEV и ссылки на записи не должны попадать в публичный репозиторий. Не коммить сам ZIP. Этот комплект не меняет видимость репозитория и не отправляет его организаторам.

## Статус проверки комплекта

Проверены JSON DEV, наличие 65 записей, правила чек-листа, ссылки на выбранные диалоги и арифметические примеры. Структура ответа и задания согласованы в комплекте. Вызов платной модели и качество её оценок здесь не проверялись: это выполнит Codex после настройки API.
